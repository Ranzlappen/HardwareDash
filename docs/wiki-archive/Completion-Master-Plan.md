# Completion Master Plan (superseded)

> **Superseded on 2026-11-18 by the v3 plan in
> [`MASTER-PLAN.md`](https://github.com/Ranzlappen/HardwareDash/blob/main/MASTER-PLAN.md).**

This page held v2's gap analysis and the W1–W10 completion workstreams (legacy
extinction, skeleton builds, consistency sweep, widgets & tiles everywhere,
permissions, root completion, high-end automation, localization, design &
assets, release). Its definition of "complete" counted seams per module —
screen, MetricSource, ActionHandler, widget/tile, rooted rows, tests, previews,
strings in four languages — rather than whether a person could use each
feature. MASTER-PLAN §2 explains why v3 changed course.

What carried over:

- **W1 legacy extinction** — done in v2 and kept (no `com.gadget` code in
  `:app`; only `:lsposed-module` remains, frozen).
- **W5 `:core:permissions`** and **W7 automation** foundations — kept as
  infrastructure.
- Everything else is either re-planned in MASTER-PLAN §6 or frozen until
  V3-5.

The full original text is on the `archive/v2-modular-2026` branch at
`wiki/Completion-Master-Plan.md`.
