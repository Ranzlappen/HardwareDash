# Wiki archive (v2-era reference)

These pages were part of the published wiki until v3 B15 (V3-5 polish).

Home, AI Collaboration, Module Authoring Contract, Design System,
Flavors & Root Safety, Troubleshooting, Roadmap & Status.

and plans; much of it is still accurate (Monitoring Framework, Automation
Engine, Widgets/Tiles, Component Catalog), some is stale (module and
feature catalogs predate the v3 merges and additions). When the code and
a page disagree, the code wins — and if a page is worth reviving, move it
back to `wiki/` and update it.

Current status lives in [Roadmap & Status](../../wiki/Roadmap-and-Status.md);
direction in [MASTER-PLAN.md](../../MASTER-PLAN.md).
